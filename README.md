## Fungsi Utama
Website portofolio pribadi untuk menampilkan profil, kemampuan, proyek yang telah dibuat, serta informasi kontak dalam tampilan modern dan responsif.

## Manfaat bagi Pengguna
- Mengenal profil dan kemampuan pengembang.
- Melihat proyek yang pernah dikerjakan.
- Memudahkan calon klien menghubungi pengembang.
- Menjadi media promosi jasa pembuatan website.

## Cara Instalasi

### Opsi 1 — Menjalankan Secara Lokal
1. Download atau clone repository.
2. Buka folder project.
3. Jalankan file `index.html` menggunakan browser.
